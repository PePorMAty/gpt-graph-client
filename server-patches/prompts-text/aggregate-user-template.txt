Ниже даны:
1) целевой продукт;
2) уже существующая производственная цепочка, которую нужно дополнить;
3) набор текстовых блоков с описаниями, на основе которых нужно достроить только ОДИН следующий шаг цепочки.

Задача:
- Проанализируй TARGET_PRODUCT и существующую цепочку.
- Определи, какой продукт нужно раскрыть следующим вверх по сырью.
- По текстовым блокам определи, из какого непосредственного бизнес-продукта или набора бизнес-продуктов этот продукт производят.
- Верни только один новый шаг, который дополняет существующую цепочку.
- Не перестраивай уже найденные шаги.
- Не строй сразу несколько новых уровней.
- Не выбирай шаг для другого продукта, даже если он описан подробнее или встречается чаще.
- Если данных недостаточно — верни только: needs-sources

Критерии:
- Узлы цепочки должны быть только бизнес-продуктами.
- Допускаются явно выделенные материальные промежуточные продукты, если они прямо выступают непосредственным входом для получения раскрываемого продукта.
- Не используй в качестве узлов операции, стадии, оборудование, режимы, катализаторы, растворители, газы-утилиты, если из текста не следует, что это самостоятельный материальный продукт цепочки.
- Предпочитай конкретные и рыночно-понятные названия продуктов, но не меняй сущность продукта ради упрощения.
- Если для одного раскрываемого продукта есть разные наборы входных продуктов — выведи альтернативы.
- Если отличия только технологические, а не продуктовые — не делай отдельную альтернативу.
- Если сомнение нельзя снять без догадки — верни needs-sources
- Если TARGET_PRODUCT = «аммиак» и из блоков прямо следует, что synthesis gas / makeup gas / pure synthesis gas подают в ammonia synthesis loop для получения ammonia, этого достаточно для шага «аммиак из синтез-газа» или «аммиак из очищенного синтез-газа».

Алгоритм (не выводить):

2) Если EXISTING_CHAIN пуста, выбери раскрываемым продуктом только TARGET_PRODUCT.
3) Если EXISTING_CHAIN не пуста, определи единственный продукт, который нужно раскрыть следующим.
4) Игнорируй шаги для других продуктов.
5) По каждому текстовому блоку проверь, есть ли явная связь:
   [непосредственный входной бизнес-продукт / входные бизнес-продукты] → [раскрываемый продукт]
6) Отбери только варианты шага для выбранного раскрываемого продукта.
7) Если для аммиака встречаются формулировки про synthesis loop / converter / reaction to produce ammonia,
   рассмотри synthesis gas / makeup gas / pure synthesis gas как допустимый непосредственный входной продукт.
8) Сгруппируй блоки по одинаковому продуктовому шагу.
9) Самый подтверждённый шаг среди вариантов для этого продукта выведи как основной.
10) Остальные шаги для того же раскрываемого продукта, если у них другой набор входных бизнес-продуктов, выведи как альтернативы.
11) Если надёжного шага нет — выведи needs-sources
